# Workflow Technical Reviews

Store one Technical Steward review companion per workflow in this directory.

Use `../templates/workflow-technical-review-template.md` and name the file after the workflow, for example:

`generate-publish-ministry-schedule-technical-review.md`

These files contain review questions, constraints, alternatives, Product Owner responses, and resolutions. They do not replace or directly modify the authoritative workflow specifications in `docs/specification/workflows/`.
